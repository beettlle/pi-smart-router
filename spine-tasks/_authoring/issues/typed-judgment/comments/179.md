## Typed-judgment research note (scope narrowed for Sprint 1)

Tracking epic for typed-judgment signals: {{EPIC}}.

We replayed this incident against a local Jev-compatible judge (OpenJev, DiffusionGemma 26B). **A judge alone does not fix this issue.** Every question set rated "Quotas has been reset, continue" in the 12,000-message session as mid-tier work (`capability_deserved` ≈ 1/3, deep reasoning 0.02–0.10) unless the state carried an explicit workspace/stakes sentence. A terse continuation hides the stakes from any prompt-level classifier.

There is also a taxonomy gap: `economical-cloud` contains both flash-class and mid-tier models, so even a correct "standard" verdict can still land on `glm-5.3-flash`.

**Scope for this issue (Sprint 1 milestone):**

- [ ] Deterministic `main_loop` capability floor on session depth / context size (existing AC: >1,000 messages or >100k estimated tokens).
- [ ] A flash-class definition for fleet profiles (capability-profile based, with the `flash|lite|mini|nano` id pattern only as a fallback) and its exclusion from deep-session `main_loop`.
- [ ] The re-check after a cross-provider handoff and top-k telemetry remain as written.

**Moved to {{T5}} (Sprint 2):** using the typed judgment (`capability_deserved`, `task_kind`) to raise the tier further. That issue must never lower below the floor delivered here.
