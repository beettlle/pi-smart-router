## Option: OpenJev models as independent offline graders

Typed-judgment epic: {{EPIC}}.

[OpenJev](https://github.com/razorback16/openjev) serves several independently trained System One models behind one Jev-compatible API: `openjev-0.1` (DiffusionGemma 26B-A4B), `laya-1.0`, `verdict-1.4`, `clm-v0.1`, and `jevk5-0.2`. Each returns calibrated yes/no probabilities and choices that cannot go off-schema. That fits the "2–3 blinded graders, generator excluded" requirement here.

Grading is offline, so judge latency does not matter. Long transcripts raise cost (state size dominates latency), so the grading state should be a compact outcome summary. Labels would still be tagged `llm_judge` and follow the existing holdout rules.

This is an option to evaluate, not a change to this issue's acceptance criteria.
